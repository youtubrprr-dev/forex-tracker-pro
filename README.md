# Forex Tracker Pro

Gold & BTC Trading Money Tracker with:
- Live prices and market analysis (Bangla)
- TradingView-style charts
- Trader Logic checklist (Breakout / Breakdown / Reverse / Trap)
- Mind Control (emotion check, cooling-off, max trades lock)
- Sign-in system
- Daily 4% max loss / 8% max profit targets
- Weekly and monthly P/L tracking

## How to use
1. Open `index.html` in any browser
2. Sign in with demo account or register a new one
3. Set your capital in Settings
4. Use Chart Analysis, Trader Logic, and Mind Control before trading
